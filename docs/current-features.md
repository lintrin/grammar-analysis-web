# Clause · 当前功能清单与开发规划基线

整理日期：2026-10-04。适用版本：规则 **0.22.4**、词典 **1.7.0**，以 [联合版本清单](../data/analysis-manifest.json) 为准。

本文按用户能力整理当前程序，供后续选题、拆分范围和制定验收标准使用。当前阶段 1–32 ✅ 已交付；同一 tab 的检查与解析流程也已交付。下面的“支持”均指**已收录词汇、已审核搭配和已开放组合**，不表示任意英文都可以分析，也不表示各项能力可以任意组合。历史归档中的“尚未支持”须结合当前版本核对。

## 1. 产品定位与使用流程

面向中文学习者的英语语法分析工作台，使用随应用打包的词典和人工规则，在浏览器内完成分析。

1. 输入一个英文句子，或从分类例句、词典教学例句中选择句子。
2. 点击分析按钮，或按 Ctrl / ⌘ + Enter。
3. 同一个「语法检查与成分解析」tab 先显示语法检查；完整匹配当前规则后自动显示成分解析。
4. 未通过时显示检测原因；符合安全门槛时提供修改建议。每次应用一条建议，自动重新检查和解析。
5. 点击成分查看原文和中文说明；多分句先查看整体关系，再进入分句查看内部结构。

“检查通过”仅表示完整匹配当前规则；没有修改建议不代表句子正确。程序不做自然表达评分、语义判断或开放英文的全面语法检查。

## 2. 已支持的语法分析

### 2.1 五种基本句型

| 句型 | 能力与示例 | 当前边界 |
|---|---|---|
| SV 主谓 | `She sleeps.` | 按动词的审核搭配匹配，不任意接受尾部成分 |
| SVO 主谓宾 | `She reads the book.` | 宾语按搭配接受名词短语或宾格代词；拥有义 have 另有限制 |
| SVC 主系表 | `The book is useful.` | be 系表，表语为单个形容词或名词短语；未开放一般地点表语 |
| SVOO 主谓双宾 | `She gives him a book.` | 接受者限人物名词短语或限定宾格代词，直接宾语要求名词短语 |
| SVOC 主谓宾宾补 | `We found the book useful.` | make/find/keep 的审核搭配，宾补限单个形容词 |

### 2.2 句子用途、肯否和疑问

| 能力 | 当前支持 | 主要限制 |
|---|---|---|
| 陈述句 | 已开放结构的肯定与限定否定 | 否定只按当前 do/be/can/have/will 结构开放 |
| 一般疑问句 | do/be/can/will 及已开放谓语链的肯定一般疑问；如 `Did she give him a book yesterday?` | 不支持否定疑问；拥有义 have 使用 do 倒装 |
| 祈使句 | 限定原形结构，显示隐含主语 you；如 `Be kind.` | 不自动继承所有动词新搭配；不支持否定祈使 |
| 感叹句 | 限定 What/How 系表结构；如 `What a useful book it is!`、`How useful the book is!` | 不支持任意感叹形式；What 名词短语的限定词受约束 |
| 特殊疑问：状语 | where/when/why；如 `Where does she work?`、`When will she read the book?` | 肯定、单简单句、简单体主动 SV/SVO；where 限六个地点动词 |
| 特殊疑问：宾语 | who/what 提问审核 SVO 的直接宾语；如 `What does she read?` | 不含双宾语接受者、SVOO/SVOC、表语或被动提问 |
| 特殊疑问：主语 | who/what；如 `Who opens the door?` | 限审核 SV/SVO；需要复数语境时不强制改为三单 |

特殊疑问均不附加地点尾部，不接完成、进行或被动谓语。主语/宾语提问可按范围带 today/yesterday，will 不带 yesterday；when 不再附加这两个时间词。疑问类型单独分类为一般疑问、主语提问、宾语提问或状语提问。

### 2.3 时态、体、语态与情态

| 能力 | 代表形式或例句 | 当前边界 |
|---|---|---|
| 一般现在／过去 | 实义动词与 be 的审核词形 | 同形词缺少明确形式线索时保留歧义 |
| 现在／过去进行 | be + V-ing；`She is sleeping.` | 状态义 know/need/want 等不开放进行体；不支持进行系动词 be |
| 现在／过去完成 | have/has/had + V-en；`She has given him a book.` | 按搭配许可；包括 been + 原有表语 |
| 完成进行 | have/has/had been + V-ing；`She has been sleeping.` | 仅已开放主动搭配，不含完成进行被动 |
| 一般时被动 | be + V-en；`The book was liked by her.` | 限审核 SVO/SVOO 的被动转换 |
| 完成被动 | have/has/had been + V-en；`A book has been given to her.` | 按被动搭配许可 |
| 进行被动 | be being + V-en；`She is being given a book.` | 按被动搭配许可 |
| can | 简单主动及 can be 系表，含限定否定和肯定一般疑问 | 不开放新的进行／完成／被动助动词链 |
| will | 五种句型的简单主动及 will be 系表；`She won’t sleep.` | 不开放 will 进行／完成／被动；if 条件从句内不开放 will |

这些谓语链在已开放搭配下支持肯定、否定陈述和肯定一般疑问；祈使、感叹、特殊疑问及新 SV 搭配不能据此自动获得同样权限。can/will 单独标为情态结构，不推断现在／过去时，也不推断说话者意图。

被动支持宾语或双宾语中的接受者／直接宾语提升，按**表层成分**标注句型；可用限定 to 短语说明接受者、by 短语说明施事，to 在 by 之前。SV、be 系表与 SVOC 不支持被动；不能据此接受通用介词短语。

### 2.4 分句与连接关系

| 结构 | 示例 | 当前范围 |
|---|---|---|
| and/but 并列 | `She sleeps and he smiles.` | 恰好两个完整陈述分句；连接词前可有一个逗号 |
| because 原因 | `She smiles because she likes the book.` | 主句在前、because 从句在后，无逗号 |
| if 条件 | `If she sleeps, he will smile.` | 条件从句在前，必须用一个英文逗号分隔主句 |

两侧均需显式主语和完整匹配，分别展示句型、时态、体、语态与情态。整体说明添加、转折、原因或条件关系。不支持共享主语、省略谓语、短语并列、三分句、嵌套从句；不推断因果语义或条件时态搭配。任一分句失败时不显示半棵成分树，原因可指出第几分句；多分句暂无自动纠错。

### 2.5 名词短语、状语与多搭配

| 能力 | 当前支持与边界 |
|---|---|
| 名词短语 | 收录名词的单复数、限定词、人称代词及前置形容词；a/an 依据人工首音数据判断。短语内形容词作为定语展示；不是任意名词短语解析器 |
| 时间状语 | 限定位置的 today/yesterday；组合与时态冲突时不自动猜测目标时态 |
| 固定目的地 | go 的 `to school`；不推广为任意目的地，简单体与时间词同用仍保留既有边界 |
| 地点状语 | sleep/work/walk/run/dance/wait 的单简单句尾部 in/on/under/near 短语，介词和地点按逐动词许可；如 `She sleeps near the tall table.`。支持简单体、进行体和 can/will 简单体，地点后可接许可的时间词；不接完成、被动、分句或任意 SVO 尾部 |
| 拥有义 have | 一般现在／过去的名词短语宾语、do 否定／一般疑问，以及已开放的陈述分句和主语／宾语提问。与完成助动词 have 区分；不接 can/will、进行／完成／被动、祈使或无需 do 的拥有疑问 |
| eat/read/write 的第二搭配 | 新增泛指活动的 SV，限定人物主语，如 `She reads.`；保留原 SVO |
| open/close 的第二搭配 | 新增门／窗／it 自行变化的 SV，如 `The door opens.`，含许可的 what 主语提问；保留原 SVO |

五个新 SV 搭配逐项限制用途、主语、体和情态，均不自动继承完成、被动、祈使、地点或分句权限。具体允许组合以 [阶段 30 能力矩阵](../data/grammar/stage30-capabilities.json) 为准。

否定陈述开放 12 种缩写：don't、doesn't、didn't、isn't、aren't、wasn't、weren't、can't、haven't、hasn't、hadn't、won't；接受直／弯撇号。have 缩写仅作助动词，保持原文区间；不支持肯定缩写、所有格、cannot 或否定疑问。

## 3. 解析展示、诊断与安全纠错

### 3.1 解析与学习反馈

- 显示用途、五种句型、简单／并列／主从结构，以及可确定的时态、体、语态、情态和疑问类型。
- 标注主语、完整谓语、直接／间接宾语、表语／宾补、状语、定语、分句与连接关系，提供中文解释与结构学习提示。
- 成分引用原始 UTF-16 区间，保留大小写、空格和重复词；疑问句谓语可分为多个区间，祈使隐含 you 不伪造原文位置。
- 可查看名词短语内部定语，进入／返回分句；键盘和手机均可操作，返回后恢复分句焦点。

### 3.2 状态与原因

| 结果状态 | 含义与界面行为 |
|---|---|
| complete | 当前规则完整匹配，检查通过并自动显示成分 |
| partial | 检测到支持上下文中的形式不匹配，可在安全条件下给出建议 |
| unsupported | 词典未覆盖、结构未开放或计算预算耗尽，提示具体已检测原因 |
| ambiguous | 存在多个解释或无法唯一确定时态，不选择一个猜测结果 |
| invalid | 空输入、超过长度限制或不合法的多句／句末标点输入 |

原因区分未知词、范围外结构、形式不匹配、标点、歧义、预算耗尽和无效输入。未知词提供“查看原文”按钮，选中输入中的对应词，不修改句子。不完整结果不进入成分解析；范围限制不等于语法错误。

### 3.3 已有纠错类别与门槛

| 类别 | 示例修改 |
|---|---|
| 主谓一致 | `She sleep.` → `She sleeps.` |
| do/does/did 后原形 | `She does not likes books.` → `She does not like books.` |
| can/will 后原形 | `She will reads the book.` → `She will read the book.` |
| 谓语组合中的有限 be/have 一致 | `She have given him a book.` → `She has given him a book.` |
| 谓语组合中的唯一分词替换 | `She has give him a book.` → `She has given him a book.` |

基础纠错可用于已开放否定、缩写、一般疑问、地点和特殊疑问上下文，但仍受完整搭配、唯一候选及各阶段门槛限制。组合谓语的建议保持原时态、体与语态；多个依赖错误、桥接错误或候选不唯一时不建议。五个新 SV 搭配仅单处词形错误可建议，多处错误只诊断。

建议保留原文格式，每次只应用一条再分析。输入编辑、例句替换、规则／词典版本或哈希变化立即清除旧结果，拒绝过期建议；分析中的旧回调不能覆盖新输入。失败时保留输入并允许重试。缺词、词序改写、冠词自动替换、拼写校正、语义与自然表达改写均不属于当前纠错能力。

## 4. 词汇搭配查询与教学例句

当前发布快照含 **231 个审核词条、44 组可数名词、24 个形容词、100 个实义动词词元和 105 个实义搭配**。功能词也随快照提供，不把词条数量当作任意英文覆盖率。

- 词汇与搭配查询默认收起；按完整词元或表面词形精确搜索，忽略大小写与首尾空白。
- 按全部词性、名词、形容词、动词或功能词筛选；同形词保留全部身份及命中词形。
- 展示词形、来源和许可，逐搭配说明用途、体、被动、情态、特殊疑问、地点与分句权限；拥有义 have 与完成助动词分别说明。
- 教学例句按钮填入原文、清除旧结果并聚焦输入，需用户再次触发分析。
- 左侧分类例句默认收起，各分类可独立展开；同时提供范围与歧义示例。

查询只支持已收录拼写，不提供模糊搜索、拼写推荐或远程查词。“未收录”不表示拼写错误。阶段 32 的独立验收句不作为网页教学素材。

## 5. 本地运行、隐私与工程能力

### 5.1 运行与隐私

- 现有交付形式为准备好依赖后的本地网页，支持开发服务和构建产物的 Wrangler 本地启动；启动命令见 [项目说明](../README.md#本地开发)。
- 静态资源加载后可断网分析、应用建议和查询；安装依赖与构建可能需要联网。
- 输入句子、搜索词与筛选状态只在浏览器内处理，不上传、不写日志、不持久保存。刷新恢复默认例句、空搜索与全部词性。
- 每次只分析一个句子，最长 **1000 UTF-16 字符**，解析共享 **4000 次边界预算**；超限明确拒绝，不输出半成品。
- 已有桌面／390px 手机、键盘、焦点、连续点击、分析中编辑取消、失败重试与版本失效回归证据。

PWA、完整离线安装包、双击启动、在线词典后台和公开部署仍属于独立待开发／交付事项。仓库的部署基础结构不等于已经上线。

### 5.2 词典维护工具（开发者能力）

本地 SQLite CLI 支持初始化／迁移、导入草稿、查询与查看、完整修订、校验、绑定当前内容哈希审核、明确选择修订发布、导出发布、从固定发布重建，以及生成／核验客户端快照。

发布不可覆盖，旧修订保留；新修订必须重新审核，拒绝未审核或过期哈希。规则版本、词典版本与哈希由联合清单锁定；构建会检查固定发布与客户端数据一致性。网页只读打包快照，不访问维护数据库，数据库不存句子或分析历史。详细流程见 [词典数据库与发布协议](lexicon-database-design.md)。

以下为**待选择的候选**，未安排实施顺序、日期或承诺版本。可在本清单基础上按教学价值和工作量制定下一轮计划。

| 候选方向 | 当前缺口 | 建议先固定的范围 |
|---|---|---|
| 地点与介词扩展 | 仅六个 SV 动词的限定尾部及现有固定短语 | SVO 地点尾部、SVC 地点表语、名词后置修饰分别规划 |
| 情态与谓语扩展 | 仅 can/will 简单链；缺更多情态及 will 组合链 | may/must/should/could 或 will 进行／完成／被动，一次固定一种范围 |
| 特殊疑问扩展 | 仅肯定简单主动 SV/SVO | be 表语提问、进行／完成提问、接受者提问分别固定角色和语序 |
| 新动词搭配与补语 | 多搭配仅先开放五个新 SV；系表和补语有限 | become/stay + 表语、want/need + to 不定式及其层级单独定义 |
| 更多从句 | 仅两个完整陈述分句的有限连接 | 关系从句、宾语从句一次一种；先定义归属、嵌套与预算 |
| 教学词汇扩充 | 闭合词典，名词／形容词覆盖有限 | 按教学场景选词与义项，审核词形、首音、搭配、来源和许可 |
| 交付方式完善 | 当前需要本地准备环境并启动网页 | 先选 PWA 或一种安装包，定义首次安装、升级和清理；不缓存用户句子 |
| 多人词典维护 | 现有本地 CLI，无在线维护后台 | 明确多人需求后设计账号权限、审核发布、远程库迁移 |

文章分析、开放词典、拼写校正、自然表达改写和跨分句自动改写属于更大范围，不能当作当前规则的小幅扩容。未来计划继续遵守 [项目开发规则](../AGENTS.md)：先固定人工预期和能力矩阵，保留历史行为回归，完成实现、检查、浏览器验收与文档后才标注 ✅。
