# 阶段 31：被动分词纠错回归修复

日期：2026-10-04。状态：✅ 实现、工程检查、开发/构建浏览器验收与文档完成。

## 问题与固定范围

原先对五个新 SV 的 `have + been + 现在分词` 无宾语结构统一拒绝，没有检查主语能否进入第二搭配。这使 `The book has been reading.` 和 `The letter has been writing.` 的唯一原 SVO 被动分词纠错也被屏蔽。

先固定 `tests/stage31.test.mjs` 中 9 个被动纠错答案和 7 个拒绝对照，再修改规则。9 个纠错用例在修复前全部失败；答案包括 read/written/eaten/opened/closed、否定复数主语、过去完成时、时间尾部与倒装疑问。断言检查唯一建议的规则、原文区间与替换、实际应用后的完整原文，以及重新分析的完成体和被动语态。

拒绝对照覆盖人物名词、复数人物、it、门窗复数、否定、过去完成与倒装疑问，保留原有五个词的 15 个完成进行拒绝用例。人物主语的 eat/read/write 和 door/window/it 主语的 open/close 仍不开放第二 SV 的完成体，也不提供改变体或语态的建议。

## 实现

`lib/grammar/composed.ts` 复用 `secondFrameSubjectPermits`，仅在主语满足第二 SV 的限制时阻止回退。传入已经解析的主语及按陈述顺序排列的谓语链，使倒装疑问使用相同的主语范围检查。其它主语继续使用原 SVO 的被动分词纠错路径。

本次收窄尚未提交的阶段 31 实现，联合版本仍为规则 `0.22.3`、词典 `1.7.0`。原有冻结答案、初稿、哈希和 2026-10-03 验收记录保留。
