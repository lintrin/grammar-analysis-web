## 原文区间与纠错

词法层识别完整白名单 token，再提供内部助动词和 not 两个虚拟解释；它们共享完整缩写的原文 `text/start/end`，不展开或清洗输入。唯一结果协议仍为 `ranges: {start,end}[]`，使用原文 UTF-16 半开区间。陈述谓语仍显示一个完整片段；分句仍以整句位置归属，肯定疑问继续使用既有不连续区间。虚拟 token 不产生重叠的显示节点，谓语解释也保留原文，不重复打印缩写。

结构校验统一拒绝成分、诊断或编辑区间拆开白名单缩写，原有代理对保护继续保留。超长输入等无位置的失败结果不需要额外词法扫描。所有共享候选/短语预算和 1000 UTF-16 输入上限保持；emoji 等未开放字符整句拒绝，位置不拆开代理对。

既有 AGREEMENT-001、DO-BASE-001、MODAL-BASE-001 可用于基础缩写结构。修改完整缩写 token，保留否定、原撇号以及现有全大写/首字母大写规则；实义动词错误仍修改其自己的原文 token。`She don't likes books.` 的两条建议分别为 don't → doesn't 与 likes → like，每次只应用一条、重新分析后再生成当前位置的剩余建议，也验证先改第二条的路径。原文多空格保持。新的 be/have 谓语组合纠错仍属于阶段 24；跨分句、未知词、范围外和否定疑问不给自动修改。
